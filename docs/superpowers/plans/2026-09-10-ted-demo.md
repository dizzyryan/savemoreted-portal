# SaveMoreTED Demo Implementation Plan

**Goal:** Build the approved presentation-only TED pre-screening journey.

**Architecture:** Expo/React Native frontend with typed in-memory state, scripted conversation, presenter-selected outcomes, and reusable UI. No backend or medical inference.

**Tech Stack:** Expo, React Native, TypeScript, react-native-svg.

**Spec:** `docs/superpowers/specs/2026-09-10-ted-demo-design.md`

## Constraints

- No migrations or `pnpm run dev`.
- Simulated capture and outcomes remain visibly labeled; no actual camera or classifier.
- Four outcomes; clinical decisions remain with professionals.
- No backend, real referrals, booking, or persistent user data.

## Tasks

- [x] Set up Expo dependencies/configuration, TypeScript, scripts, and README in the empty repository.
- [x] Add `src/demo.ts` for questions, capture steps, four sample outcomes, and report serialization.
- [x] Add `src/ui.tsx` and `src/illustrations.tsx` for accessible native controls, responsive styling, and bundled illustrations.
- [x] Add `src/screens/Home.tsx`, `Questionnaire.tsx`, and `Capture.tsx` for introduction and the guided journey.
- [x] Add `src/screens/Results.tsx`, `Referral.tsx`, and `Report.tsx` for sample results, mock consultation preparation, and user-initiated report export.
- [x] Wire screens in `App.tsx` with reset/back navigation, completion checks, and presenter controls.
- [x] Run `npm run typecheck`, web export, and iOS/Android bundle export; inspect browser walkthrough and narrow viewport. Document actual checks and any unavailable native-device verification.

Manual interaction checks are appropriate for this reversible presentation prototype. Add automated behavioral checks if integration issues warrant them; avoid tests that merely duplicate static demo data.

## Verification outcome

TypeScript and web/native bundle exports pass. The browser walkthrough verified the planned UI flows. Browser download completion and physical-device/native-share testing remain unverified, as documented in README.md. No backend, migrations, development server, or clinical inference was introduced.
